01 The file concept

What is a file?

A file is a named collection of data stored on a device like a hard disk or SSD. It can hold text, images, audio, video or program code. Type any name below to take it apart.

File name
TYPE 1

Regular files

The most common kind: data that users and programs read and change directly.

notes.txtphoto.jpgmain.c
TYPE 2

Special (device) files

Stand for hardware such as printers, keyboards or disks, so programs can talk to devices like files.

/dev/sda/dev/tty
TYPE 3

Directory files

Containers that hold the names, attributes and locations of other files, forming a tree.

Documents//home/

Ways to share files

P2P

Peer-to-peer

Users connect directly, with no central server. Often used for large files.

Cloud

Cloud-based

Files live on remote servers you reach from any device, like Google Drive, Dropbox or OneDrive.

Direct

Direct transfer

Device to device over Bluetooth or Wi-Fi Direct, common on phones.

Media

Removable media

USB drives or external disks passed from hand to hand.

Risks, and how to protect against them

Risks

Malware & viruses: files from untrusted sources can infect devices.

Data breaches: badly secured cloud or P2P sharing can leak sensitive data.

Legal trouble: sharing copyrighted material can bring lawsuits and fines.

Identity theft: logins or personal details shared by accident.

Protection methods

Encryption: data is coded and readable only with the key. Use when sending confidential files.

Password protection: a password is needed to open the file.

Secure transfer protocols: SFTP and HTTPS encrypt files in transit.

Firewall: watches network traffic and blocks unauthorised access.
